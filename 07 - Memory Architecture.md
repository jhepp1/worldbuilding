# Memory Architecture

The Centre can alter how residents remember their lives.

The process is not experienced as forgetting.

Instead, old memories are gradually replaced or reconstructed.

## The Critical Feature

Residents cannot reliably compare the new memory against the old one.

If a memory is completely overwritten, the resident does not think:

> I remember this differently.

The original version is no longer available as a reference.

## Centre Anchoring

Memories of the outside world can become associated with the Centre.

For example:

-   A meal once remembered at home becomes a meal in a Centre café.
-   A childhood garden becomes a Centre garden.
-   An old conversation becomes a conversation beside the Centre
    fountain.
-   A former bedroom acquires details resembling the resident's current
    room.

The resident experiences the replacement memory as authentic.

## Result

The Centre gradually becomes the emotional setting for more and more of
the resident's life.

Eventually the outside world can remain as an abstract fact while the
Centre feels like the place where the resident's life has always
happened.
